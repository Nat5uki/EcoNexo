EcoNexo 🌱
Pequenas atitudes, grandes mudanças.

O EcoNexo é uma landing page educativa sobre sustentabilidade no dia a dia. O projeto apresenta hábitos e práticas que ajudam a reduzir impactos ambientais e incentiva as pessoas a adotarem escolhas mais conscientes.
✨ Funcionalidades
- Página inicial: apresentação do EcoNexo e chamada para explorar o conteúdo.
- Bons hábitos: dicas sobre participação comunitária, energias renováveis e redução do desperdício de alimentos.
- Métodos de sustentabilidade: seção com conteúdos sobre economia de água, reciclagem, consumo consciente, economia de energia, reutilização de materiais e transporte sustentável.
- Janelas modais: cada tema da seção de sustentabilidade pode ser aberto para consultar explicações e sugestões práticas.
- Timeline: seção com marcos e informações sobre sustentabilidade.
- Formulário de inscrição/contato: área para o visitante preencher seus dados.
- Layout responsivo: adaptação para diferentes tamanhos de tela, com navegação responsiva.

🚀 Como executar localmente
1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code ou em outro editor.
3. Abra o arquivo index.html no navegador.
Para facilitar o desenvolvimento, você também pode utilizar a extensão Live Server no Visual Studio Code: clique com o botão direito em index.html e selecione Open with Live Server.
🌐 Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie os arquivos do projeto para a raiz do repositório.
3. Acesse Settings → Pages.
4. Em Build and deployment, selecione a publicação a partir de uma branch.
5. Escolha a branch principal (por exemplo, main) e a pasta / (root).
6. Salve e aguarde a publicação. O GitHub fornecerá o endereço público do site na seção Pages.
📝 Observações
- O site carrega algumas bibliotecas, fontes e scripts externos pela internet; a conexão é necessária para que esses recursos sejam carregados.
- O formulário está presente na interface, mas o envio real de dados depende de configuração de um serviço de formulários ou de um backend.
- O conteúdo tem finalidade educativa e busca incentivar hábitos mais sustentáveis.
🎯 Objetivo do projeto
Compartilhar informações simples e práticas sobre sustentabilidade, mostrando como pequenas mudanças de hábito — como economizar água e energia, reciclar, reutilizar materiais e escolher meios de transporte menos poluentes — podem contribuir para um futuro mais sustentável.
Projeto desenvolvido com base no template Agency do Start Bootstrap e personalizado para o tema de sustentabilidade.
